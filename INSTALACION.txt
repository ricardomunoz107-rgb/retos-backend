GUIA RAPIDA - PROYECTO RETOS
============================

Requisito:
- Python 3.13 o una version compatible con Django 6.1.1

1. Abrir PowerShell en la carpeta del proyecto
------------------------------------------------
cd C:\ruta\de\tu\proyecto

2. Crear el entorno virtual (solo la primera vez)
--------------------------------------------------
py -m venv .venv

3. Activar el entorno virtual
------------------------------
.\.venv\Scripts\Activate.ps1

Si PowerShell bloquea la activacion, ejecuta una sola vez:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Luego vuelve a activar:
.\.venv\Scripts\Activate.ps1

Si usas CMD en lugar de PowerShell:
.venv\Scripts\activate.bat

4. Instalar todas las dependencias
-----------------------------------
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

5. Configurar el entorno local
------------------------------
Copy-Item .env.example .env

La plantilla usa SQLite. Para PostgreSQL, configura las variables DB_* en
.env y prepara la base de datos con scripts\init_db.sql.

6. Preparar la base de datos
-----------------------------
python manage.py migrate

7. Comprobar que el proyecto esta correcto
--------------------------------------------
python manage.py check

8. Ejecutar pruebas y levantar el servidor
-------------------------------------------
python manage.py test
python manage.py runserver

Abrir en el navegador:
http://127.0.0.1:8000/

Para que otros equipos de la misma red puedan verlo:
python manage.py runserver 0.0.0.0:8000

Antes de compartir el servidor, agrega la IP o el nombre del equipo a
ALLOWED_HOSTS en .env.

Importante:
- El entorno virtual se activa en cada nueva terminal.
- La carpeta .venv NO se sube a GitHub; se reconstruye con requirements.txt.
- El archivo .env contiene valores locales y no se sube a GitHub.
- No cierres la terminal mientras el servidor este funcionando.
- Detener el servidor: Ctrl+C
